# Kebijakan Keamanan — bct-website

## Praktik yang diberlakukan (dijaga oleh agent security-auditor & CI)

1. **Headers**: CSP ber-nonce per request (`proxy.ts` + `lib/csp.ts`: `script-src 'self' 'nonce-…' 'strict-dynamic'`, tanpa `'unsafe-inline'`; `'unsafe-eval'` hanya `next dev`), X-Content-Type-Options, X-Frame-Options DENY, Referrer-Policy, Permissions-Policy, COOP di `next.config.ts`; HSTS di middleware `security-headers` Traefik (repo infra). Pelonggaran apa pun butuh justifikasi tertulis + persetujuan owner. Satu-satunya tambahan bersyarat: bila Turnstile aktif (G-43, keputusan owner 2026-09-26) `https://challenges.cloudflare.com` masuk `script-src` (fallback non-CSP3; di CSP3 `'strict-dynamic'` yang berlaku) dan `frame-src 'self' https://challenges.cloudflare.com` ditambahkan — nihil bila env Turnstile kosong. Tambahan bersyarat kedua: bila Umami aktif (G-47, `UMAMI_SCRIPT_URL` + `UMAMI_WEBSITE_ID`) origin yang diturunkan dari `UMAMI_SCRIPT_URL` (https saja, tanpa wildcard) masuk `script-src` (fallback non-CSP3) dan `connect-src` (`/api/send`); tag skripnya membawa nonce request — nihil bila env Umami kosong. Guard `scripts/check-csp.mjs` memeriksa header yang benar-benar dikirim image di smoke test CI.
2. **Input publik**: semua API route memvalidasi dengan zod, method-restricted, rate-limited (per IP = entri `X-Forwarded-For` paling kanan yang ditulis Traefik — container wajib tanpa port publik), dan form publik memakai honeypot. `/api/lead` juga dipagari **anggaran kirim** (G-42: ≤ 20 kiriman/jam situs, ledakan 8, ≤ 3/hari per IP — di bawah batas mailbox 30/jam) yang dihitung sama untuk kiriman sah dan jebakan, dan **Cloudflare Turnstile opsional** (G-43: verifikasi server `success` + `hostname` + `action`, token sekali pakai; gagal → 403 generik yang sama dengan penolakan bot lain). Kiriman jebakan honeypot **tidak pernah diteruskan** (nol email, nol webhook — G-44); waktu dan statusnya ditiru dari kiriman sah nyata. Data lead minimal (nama, kontak, pesan) — selaras UU PDP No. 27/2022. Lead diteruskan lewat email SMTP (TLS wajib: 465 implisit / STARTTLS wajib di port lain, sertifikat diverifikasi; teks polos; subjek tanpa karakter kontrol; Reply-To hanya email pengunjung yang sah) ke alamat BCT yang tersimpan sebagai konstanta server-only (`lib/lead-recipient.ts`), plus webhook opsional — tidak disimpan di situs.
3. **Secrets**: tidak pernah di repo. `.env.example` mendaftar semua variabel; gitleaks berjalan di CI (full history) dan di hook `.githooks/pre-commit`; Semgrep + Trivy (fs, config, image) memblokir temuan HIGH/CRITICAL. Guard `scripts/check-pii.mjs` memfailkan build bila email/lokasi owner atau alamat penerima lead (`PENERIMA_LEAD`) terbit ke artefak klien. Password SMTP dan secret Turnstile hanya lewat file secret (`SMTP_PASSWORD_FILE`, `TURNSTILE_SECRET_FILE`, mount read-only) — tidak pernah di env, repo, atau log.
4. **Dependency**: `npm audit --omit=dev --audit-level=high` di CI — temuan high/critical memblokir merge. Dependency baru wajib berjustifikasi di PR.
5. **Docker**: multi-stage, base `node:24.21.0-alpine` di-pin digest, uid 1001 non-root, npm dibuang dari runner, standalone output, HEALTHCHECK `/api/health`; dijalankan read-only + tmpfs, `cap_drop: ALL`, `no-new-privileges`, limit mem/cpu/pids (template infra), di belakang Traefik tanpa port publik.
6. **CI**: permission `GITHUB_TOKEN` minimal (`contents: read`; `packages: write` hanya job `image`), semua action di-pin SHA, image push ke GHCR hanya setelah semua pemeriksaan + smoke test hijau.
7. **Analytics**: Umami self-host saja — tidak ada tracker pihak ketiga. Tanpa cookie, `data-exclude-search="true"` (query string tidak dikirim) dan `data-do-not-track="true"` (pengunjung dengan Do Not Track tidak dicatat) — keduanya disetujui owner di GATE 1 infra plan 11 (2026-09-27), konstanta `OPSI_PRIVASI_UMAMI` di `lib/umami.ts`; `data-domains` = host `SITE_URL` (ADR 2026-09-27 "Umami runtime"). Penjelasan untuk pengunjung: halaman `/privasi` (G-48) — ubah bersamaan bila opsi ini berubah.
